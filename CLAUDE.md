# Project Rules

## Strictly local only

Nothing from this project may leave this machine. No trace of the project should pass to the Claude web.

- Never `git push`, or run any other remote git operation (no pushing branches/tags, no creating PRs, no adding remotes).
- Never create Artifacts or Claude Docs, or use any claude.ai-connected tool (Artifact, ArtifactData, ArtifactComments, `mcp__claude_ai_*`, etc.) with project content.
- Never upload or send project files, code, or data to any external service, including web fetches or searches that embed project content.
- Use only local file and shell tools. Commits are fine only when the user asks, and they stay local.
